# Keitaro Campaign Creator — Часть 1: «Создаватор» кампаний

Веб-сервис на FastAPI для быстрого создания кампаний в Keitaro через Admin API v1.

## Что делает сервис

Принимает **название кампании**, **гео-код(ы) страны** и **оффер** (с автокомплитом по локальному кэшу офферов из Keitaro) и создаёт кампанию с двумя потоками:

1. **Flow 1 (по гео)** — принимает трафик из указанной страны и редиректит на `REDIRECT_URL` (по умолчанию Google).
2. **Flow 2 (остальной трафик)** — ведёт на выбранный оффер.

Домен, группа кампаний и источник трафика автоматически подтягиваются из API Keitaro (приоритет отдаётся значениям из `.env`, если их нет — берётся первая активная запись). При ошибке создания потоков созданная кампания откатывается (`DELETE /campaigns/{id}`).

## Быстрый запуск

### 1. Подготовка окружения

Требуется Python 3.10+.

```bash
# Создание и активация виртуального окружения (Windows PowerShell)
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Для Linux / macOS:
# source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте `.env.example` в `.env` и укажите доступы к вашему трекеру:

```bash
cp .env.example .env
```

**Обязательные параметры в `.env`:**
- `KEITARO_URL` — адрес трекера (например, `https://tracker.example.com`)
- `KEITARO_API_KEY` — API-ключ из админки Keitaro

**Опциональные параметры** (если не заданы, используются значения по умолчанию или первые доступные сущности из API):
- `KEITARO_DOMAIN`, `KEITARO_GROUP`, `KEITARO_SOURCE` — предпочтительные домен, группа кампаний и источник трафика
- `REDIRECT_URL` — URL для редиректа в первом потоке (по умолчанию `https://google.com`)

### 3. База данных и миграции

В проекте используется локальная база данных **SQLite** (`app.db`) и ORM **SQLAlchemy** для двух таблиц:
- кэш офферов (`Offer`) для быстрого автокомплита;
- локальный журнал созданных кампаний (`CampaignLog`).

Отдельный инструмент миграций (например, Alembic) не требуется: **схема БД создаётся автоматически при старте приложения** (`app.db` появится в корне проекта после первого запуска).

Если нужно сбросить локальную базу и кэш офферов, достаточно остановить сервер, удалить файл `app.db` и запустить приложение заново.

### 4. Запуск сервера

Из корня проекта выполните:

```bash
uvicorn app.main:app --reload
```

После запуска откройте в браузере: **http://127.0.0.1:8000**

## Запуск тестов

Тесты работают против локального мок-сервера Keitaro и не требуют реального API-ключа.

Из корня проекта:

```bash
python -m pytest
```

Или через стандартный `unittest`:

```bash
python -m unittest discover -s tests -v
```

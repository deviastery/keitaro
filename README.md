# Keitaro Campaign Tools

Репозиторий содержит две независимые части проекта для работы с **Keitaro Admin API v1**.

**Общий стек:** Python 3.10+, FastAPI, SQLAlchemy (SQLite), чистый HTML/CSS/JS.

## Структура репозитория

- **`keitaro-campaign-creator/`** — **Часть 1: «Создаватор» кампаний**  
  Веб-интерфейс и API для быстрого создания кампаний в Keitaro с двумя потоками (редирект по выбранным гео + поток на выбранный оффер), локальным кэшем офферов для автокомплита и автоматическим подбором домена, группы и источника.  
  → Подробная документация и запуск: [`keitaro-campaign-creator/README.md`](./keitaro-campaign-creator/README.md)

- **`keitaro-campaign-editor/`** — **Часть 2: Редактор существующей кампании**  
  Веб-интерфейс и API для управления офферами в потоках существующей кампании: загрузка актуальных потоков (`Fetch`), локальный черновик с пересчётом процентов, закрепление долей (`pin`), отображение удалённых офферов (`removed` / `Bring back`) и отправка изменений на сервер (`Push to KT`).  
  → Подробная документация и запуск: [`keitaro-campaign-editor/README.md`](./keitaro-campaign-editor/README.md)

## Запуск и тесты

Оба проекта полностью автономны: у каждого свой `requirements.txt`, `.env.example`, локальная база SQLite (`app.db`) и набор автотестов. Инструкции по установке, настройке и запуску описаны в `README.md` внутри соответствующей папки.
